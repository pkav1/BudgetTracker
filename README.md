# Budget Tracker

A personal budget tracker with Revolut CSV import, weekly planning, and savings vault tracking.

## Setup

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Accounts supported

- ✅ Revolut (CSV export)
- 🔜 AIB
- 🔜 BOI

## Features

- Weekly budget planning by category
- Revolut CSV import with auto-categorisation
- Manual savings vault tracking
- Spending vs budget charts
